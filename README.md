# PhotoTimeFixer（上游说明）

修复安卓（特别是小米 MIUI/HyperOS）照片/视频时间线排序错乱的小工具。

## 背景问题

通过数据线拷贝、小米互传等方式把照片/视频传到手机上后，在相册「全部照片」里显示的时间会变成**传输那一刻**，而不是真实的拍摄时间；但点进详情又能看到正确的拍摄时间。

原因：安卓系统媒体库（MediaStore）里有三个时间字段——

| 字段 | 含义 | 能否被第三方 App 修改 |
| :--- | :--- | :--- |
| `date_modified` | 文件修改时间（相册排序用这个） | ✅ 可改 |
| `date_taken` | 拍摄时间（来自 EXIF） | ❌ 系统只读，但可通过「重新扫描」重建 |
| `date_added` | 添加到媒体库的时间 | ❌ 系统只读，但重新入库时按文件修改时间重建 |

相册「按日期分组」用 `date_taken`，「同一天内排序」用 `date_modified`（文件修改时间）。

> **HyperOS 4 用户**：新相册已支持自定义排序——在「全部照片」或「照片首页」右上角把排序规则改为「**按拍摄时间排序**」即可解决相册内的时间线问题。设置后，本项目的主要价值就变成下面这一点。

## 本项目解决什么

- **相册内时间线乱**：低版本 MIUI/HyperOS 相册不支持按拍摄时间排序时，修复文件时间 + 重建 `date_taken` 即可让相册按拍摄时间分组排列。
- **第三方 App 调用相册时时间线乱**：微信等 App 的图片/视频选择器按「添加到媒体库的时间」（`date_added`）排序，而不是拍摄时间，导入的照片会整体错位。本工具修复时会**删除媒体库记录并触发重新扫描**，`date_added` 会按修复后的文件时间重建，因此第三方选择器的时间线也会恢复正确。
- 两类问题一次修复：修复流程同时重建 `date_modified`、`date_taken`（按文件时间）与 `date_added`（按文件修改时间），相册和第三方 App 都能恢复正常排序。

## 本项目包含两部分

### 1. 安卓 App（修复照片 + 视频）

**目录**：`app/`，包名 `com.sirandev.phototimefixer`

**功能**：
- 自动扫描相册全部照片与视频，把「文件时间 ≠ 拍摄时间」的媒体标红识别；
- 阈值可调（1 分钟 / 10 分钟 / 1 小时 / 1 天）；
- 修复方案可选（设置页切换，默认方案一）。两个方案都会把正确时间**统一写入照片的拍摄/修改/创建时间**（EXIF 三字段 + 文件时间，可关），保证修复后相册日期不再被系统按旧 EXIF 还原；EXIF 三字段已一致的照片会自动跳过重写：
  - **方案一（拍摄时间）**：直接以 EXIF 拍摄时间为正确时间（仅限 EXIF 中有拍摄时间的照片）；
    - 可选开关「**按 EXIF 时间重命名文件名**」：文件名时间与拍摄时间不符时（如相差 8 小时、老设备文件名错误），修复时按 EXIF 时间重命名，保留原命名前缀与风格（如 `IMG_20230905_143022.jpg` → `IMG_20230505_223022.jpg`）；文件名乱码/无法解析时间的不做重命名；开启后扫描也会把「文件名时间 ≠ 拍摄时间」的照片标红，可直接「全选异常」批量修复；**执行前会弹窗列出新旧文件名，需二次确认**；
  - **方案二（文件名时间）**：从文件名解析拍摄时间（如 `IMG_20230905_143022.jpg`、`Screenshot_2023-09-05_14-30-22.png`），适合 EXIF 缺失或损坏的照片；解析失败自动回退到方案一。仅含日期的文件名（如 `IMG-20230905-WA0001.jpg`）取当日 12:00，**执行前同样需二次确认**；
- **视频修复**（等价于下方电脑端脚本的能力，手机上直接完成）：
  - 视频拍摄时间以**文件名时间戳**为准（如 `VID_20260716_200546.mp4`），文件名无时间戳时回退读取 MP4 容器（`mvhd`）内的时间；
  - 修复时把正确时间**原位写入** MP4 容器的 `creation_time` / `modification_time`（等价于 ExifTool 写 QuickTime:CreateDate/ModifyDate）——只改文件内几处字节，不重写文件，GB 级视频也是毫秒级完成，且正确时间随文件走，之后再次拷贝/互传也不会丢失；
  - 同时把文件修改时间改为拍摄时间并触发重建媒体库记录，相册分组与第三方选择器时间线一并恢复；
  - 支持 MP4 / MOV / M4V / 3GP 容器；MKV / WebM 只修文件时间，不改容器（会静默跳过）；**执行前需二次确认**；
- 支持手动多选，也可以「全选异常」一键勾选；
- 点击缩略图跳转到相册对应媒体；
- 一键修复：把文件时间改回拍摄时间，并触发系统重新扫描重建拍摄时间。

**权限**：
- `READ_MEDIA_IMAGES` / `READ_MEDIA_VIDEO`（Android 13+）/ `READ_EXTERNAL_STORAGE`（Android 12 及以下）：读取照片与视频列表；
- `MANAGE_EXTERNAL_STORAGE`（所有文件访问权限）：修改媒体文件时间。Android 11+ 需在系统设置中手动授予。

**说明**：
- **首次使用会弹出风险公告，需逐字输入声明文字确认后才能使用**（仅一次）；
- **安全红线：没有可靠拍摄时间依据的媒体一律跳过，不做任何修改**——照片需 EXIF 拍摄时间或可解析的文件名时间，视频需文件名时间或容器时间；被跳过的数量会在执行前的确认弹窗中如实告知；
- 照片的「显示时间异常」——无论跨天（分到错误的日期）还是同一天内（顺序错位）——都可以修复；
- 修复会同时重建 `date_taken` 与 `date_added`，第三方 App（如微信）媒体选择器的时间线也会恢复按拍摄时间排列。微信有自己的媒体缓存，修复后建议重启微信（或结束后台进程）再查看；
- 处理完成后建议**重新打开相册**（或下拉刷新），排序才会立即更新。

### 2. 视频时间脚本（电脑端）

> App 内已支持视频修复（见上），本脚本适合**在电脑上批量处理尚未导入手机的视频**，两者能力等价。

**目录**：`video_time_fixer/`（含 `set_video_time.py`、`设置视频时间.bat`、`tools/exiftool.exe`）

**用途**：把脚本所在文件夹（含子文件夹）下所有视频文件的**文件时间**统一改为各自的**拍摄时间**。

**用法**：
1. 把 `video_time_fixer/` 整个文件夹（脚本 + bat + tools）复制到视频所在文件夹；
2. 双击 `设置视频时间.bat`；
3. 处理完成后，把整个文件夹重新导入手机（复制或 adb push 都会保留文件时间），相册会按拍摄时间重新分组。

**依赖**：ExifTool（已内置在 `video_time_fixer/tools/`，脚本会自动查找）。

> 视频脚本修改的是「文件修改时间」，重新导入后相册会按拍摄时间正确分组；处理完成后同样建议重新打开相册刷新。
